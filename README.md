# 4th School On Underground Physics: notes

This document is collecting all the content of the lectures of the 4th edition of the School On underground Physics in a single document. 
The aim is to provide a shallow review of the topics discussed, and reorganise the content in a more organic matter. 
Clearly all the intellectual propriety is of the lecturers, as this is merely a rewriting of some of my hand-notes, the slides as well as, where needed, some independent research.
